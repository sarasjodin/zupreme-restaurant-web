Om Zuprême

Fransk lantkänsla möter modern restaurang.

Zuprême är ett fiktivt soppkoncept där varje rätt presenteras med tydlig temperatur, styrka och visuell identitet. Menyn hämtas dynamiskt från ett API och kan uppdateras via ett skyddat adminsystem.
